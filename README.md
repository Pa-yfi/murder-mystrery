نسخه ۳.۱ — ۱۸ نقش، ۴۰ پرونده، ۴ تا ۱۰ بازیکن، بدون LLM، **پنل ادمین روی SQLite**.

## راه‌اندازی (PowerShell / ویندوز)
```powershell
cd "مسیر پروژه"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env      # بعد BOT_TOKEN و BOT_USERNAME و ADMIN_IDS را داخلش بگذار
python -m pytest -q tests --ignore=tests/quality   # ۲۳۵ تست سبز
python run.py               # ربات بالا می‌آید
```
لینوکس/مک: `source .venv/bin/activate` و `cp .env.example .env`.

## اگر ربات جواب نمی‌دهد (چک‌لیست)
1. **در گروه ساکت است؟** BotFather → Bot Settings → **Group Privacy → Turn OFF**.
2. **دو نسخه هم‌زمان اجرا شده؟** خطای `Conflict: terminated by other getUpdates`. همه‌ی پایتون‌ها را ببند، یکی را اجرا کن.
3. **توکن درست است؟** در مرورگر: `https://api.telegram.org/bot<TOKEN>/getMe` باید `"ok":true` بدهد.
4. **BOT_USERNAME** باید دقیقاً یوزرنیم ربات باشد، وگرنه لینک‌های دعوت خراب‌اند.

## جریان بازی
`/start` → منوی اصلی → «🎮 شروع بازی» (پنل میزبان) → دعوت دوستان/گروه
→ ۴ تا ۱۰ نفر → «✅ آماده‌ام» (همه) → «🎬 شروع» → «🔐 نقش من» (پیوی)
→ 🌙 شب → ☀️ صبح → 💬 گفتگو → 🗳️ رای
→ 🔦 متهم وارد اتاق بازجویی می‌شود (بقیه همان شب اکشن شبانه دارند)
→ 💬 گفتگوی واقعیِ بازجو و متهم در پیوی → 📕 پایان گفتگو → 🔦 سرنخ پایانی
→ تازه آن وقت: 🔒 حبس موقت (۲ شب کامل) · ⚖️ هیئت دو نفره · 🕊️ آزادی
→ 🔒 حبس موقت: آزادی فقط با 🗳️ رای شهر وقتی متهم تازه‌ای وارد شود
→ ⛓️ حبس ابد (بدون افشای نقش)
→ 🏁 پایان (نقش‌ها فاش می‌شود).

**در پیوی:** فرمان‌های خصوصی (`/act` ، `/myrole` ، `/notes` …) خودشان بازیِ
گروهت را پیدا می‌کنند. اگر هم‌زمان در چند بازی باشی، با `/table` میز فعال را انتخاب کن.

## پنل ادمین (SQL)
فقط آیدی‌های `ADMIN_IDS`: `/admin` ، `/admin_games` ، `/admin_users [id]` ، `/admin_stats` ، `/admin_ban <id>` ، `/balance`.

⚠️ فهرست خالی `ADMIN_IDS` یعنی **هیچ‌کس** ادمین نیست (قبلاً یعنی «همه»).

جدول‌های `karagah.db`: `users` ، `games` ، `players` ، `events` ، `outcomes` (تعادل) ،
`snapshots` (بازیابی بعد از ری‌استارت) ، `season_xp` ، `achievements` ، `missions` ، `accuracy`.

## نسخه ۳.۱ — ۱۰ بهبود کیفیت
- **✅ آمادگی پیش از شروع:** لابی دکمه‌ی «آماده‌ام» دارد که دیپ‌لینک پیوی است؛
  تا ربات نتواند به کسی پیام خصوصی بدهد بازی شروع نمی‌شود (`/startgame force` برای رد شدن).
- **🎯 پنل اکشن خصوصی:** `/act` هدف‌ها را با **نام** نشان می‌دهد — دیگر آیدی عددی تایپ نمی‌کنی.
- **📋 داشبورد راهنما:** فاز، مهلت، وضعیت همه، «منتظر چه کسی هستیم» و «قدم بعدی» در یک پیام.
- **🔬 مدرکِ واقعی:** ملاقات‌های شبانه رد می‌گذارند؛ هم‌مکان‌ها خصوصی همدیگر را می‌بینند
  و می‌توانند شهادت بدهند — یا دروغ بگویند.
- **🏁 پایان قابل‌فهم:** چرا این تیم برد، سرنوشت هر نقش، بی‌گناهِ حبس‌ابدی، رای‌های درست، MVP.
- **⏸️ بازیکن غایب:** `/remind` ، `/pause` ، `/resume` ، `/host` (انتقال میزبانی)، شمارش شب‌های بی‌حرکت.
- **📊 تعادل بازی:** `/balance` (ادمین) — نرخ برد هر نقش، طول بازی به تفکیک تعداد بازیکن، نرخ رهاشدگی.
- **🧪 تست بازیِ کامل:** بازیِ سرتاسری، بازیِ تایمرمحور، هیئت منصفه، ری‌استارت، و شکست پیام خصوصی.

دستورهای تازه: `/act` `/ready` `/remind` `/pause` `/resume` `/host` `/table` `/balance`

## دو سوئیت تست

## 🎛️ همه‌چیز با دکمه
هیچ بازیکنی لازم نیست دستور تایپ کند. «🎛️ همه‌ی دکمه‌ها» روی منوی اصلی،
هر ۸۱ فرمان را در هشت دسته نشان می‌دهد:
🎮 بازی · 🔦 بازجویی و دادگاه · 🔎 مدارک و دفترچه · 🔪 کارهای شبانه‌ی قاتل ·
🏆 پیشرفت · ⚙️ میز و میزبانی · 📚 راهنما · 🛠️ ادمین

**وسط بازی** فقط دسته‌های مربوط به همان دور دیده می‌شوند، و داخل هر دسته
فقط دکمه‌هایی که *همین بازیکن* حق زدنشان را دارد: شهروند دکمه‌ی پلیس یا
جعبه‌ابزار قاتل را اصلاً نمی‌بیند.

**قاعده:** هر فرمانی که ورودی می‌خواست، حالا بدون ورودی فهرست دکمه‌ها را می‌دهد.

| قبلاً تایپ می‌کردی | حالا |
|---|---|
| `/lab E2` | 🧪 آزمایشگاه → «🧬 DNA (E2)» |
| `/interp E2:1` | 🧠 تفسیر مدرک → مدرک → تفسیر |
| `/expose E4` | 🔍 راستی‌آزمایی → دکمه‌ی همان مدرک |
| `/sos 5` | 🚨 رای اضطراری → دکمه‌ی نام بازیکن |
| `/night 5` | 🌙 اکشن شبانه → دکمه‌ی نام هدف |
| `/host 3` | 👑 انتقال میزبانی → دکمه‌ی نام بازیکن |
| `/clear 4` | 🕊️ بازبینی آزادی → رای‌گیری شهر برای هر زندانی |
| `/admin_ban 77` | 🚫 مسدودسازی → دکمه‌ی نام کاربر |

**توانایی نقش‌ها:** «🎭 کاتالوگ نقش‌ها» ۱۸ دکمه دارد — هر کدام تیم، کار شبانه
و توضیح همان نقش را نشان می‌دهد. «🎯 توانایی‌های من» هم می‌گوید *همین حالا*
در این فاز چه کاری از تو برمی‌آید.

**تنها جایی که تایپ لازم است** متن آزاد است: 📝 یادداشت، 📜 وصیت‌نامه،
💬 پرسش از متهم، 🗣️ پاسخ متهم، 🧾 سرنخ جعلی، 🛡️ دفاع. دکمه را می‌زنی، ربات می‌پرسد، پیام بعدی‌ات همان متن است
(«✖️ بی‌خیال» برای انصراف).

```powershell
python runner.py            # فهرست کارها

python runner.py check      # پایتون، وابستگی‌ها، .env، توکن، JobQueue، جدول‌ها
python runner.py selftest   # ۱۳ ماژول، ۶۹ اندپوینت، فاز، یک بازی کامل — بدون شبکه
python runner.py demo       # یک بازی کامل را چاپ می‌کند (--players ۸ --case ۳)
python runner.py buttons    # درخت کامل دکمه‌ها
python runner.py roles      # ۱۸ نقش و ترکیب‌ها
python runner.py cases      # ۴۰ پرونده
python runner.py db         # جدول‌ها و تعداد ردیف‌ها
```

عوض نمی‌کنند (همه روی دیتابیسِ حافظه کار می‌کنند). `run.py` هم مثل قبل کار می‌کند.

## نسخه ۴.۰ — دسترسی نقش‌محور، پرونده‌ی خودرو، و بازداشت نسخه ۲

پیاده‌سازی قراردادهای `hints.md` §۱۲/§۱۳ و `rules.md` v2.

**دسترسی اختصاصی هر نقش** — «🗂️ بایگانی نقش من» در پیوی: پرونده‌ی درمانگاه
(پزشک)، پرونده‌های پلیس (بازجو)، کالبدشکافی، دفتر مشاهدات، دفتر نگهبانی،
بایگانی تحریریه، دفتر دادگاه، بی‌سیم پلیس، شایعه‌ی روزانه. بازداشت دسترسیِ
تازه را معلق می‌کند؛ مرگ و تسلیم آن را می‌گیرند — ولی بایگانیِ قبلی همیشه
خواندنی می‌ماند.

**پرونده‌ی خودرو** — رنگ و مدل علنی، شناسه‌ی پلاک (آشکارا ساختگی: `SIM-###`)
فقط در پیویِ پلیس. استعلام مالک: یک بار در هر شب، نتیجه سحر. قاتل یک بار
می‌تواند سند را جعل کند.

**بازداشت نسخه ۲ (rules.md v2)**
- گفتگوی *واقعیِ* دو آدم: ربات هرگز به‌جای متهم جواب نمی‌سازد.
- دروازه‌ی تصمیم: گفتگوی بسته + سرنخ پایانیِ خوانده‌شده. پیش از آن، حکم ممکن نیست.
- گفتگوی ناتمام → آزادیِ تشریفاتی، نه محکومیت.
- ⚖️ هیئت *دو نفره*: ربات دو شهروندِ تبدیل‌نشده را برمی‌دارد؛ هر دو باید «حبس»
  بدهند وگرنه متهم آزاد می‌شود.
- 🔒 حبس موقت = دو شبِ کاملِ بعدی، در همه‌ی حالت‌ها (بلیتز کوتاهش نمی‌کند).
- 🗳️ آزادی با رای شهر وقتی متهم تازه‌ای وارد بازجویی شود — بازجو یک‌طرفه
  آزاد نمی‌کند.

**تابلوی زنده** — «آماده‌ام» و «رای» از پیوی زده می‌شوند و ساعت‌شنیِ کنار اسم
در پیام گروه همان‌جا به ✅ می‌چرخد.

**منوی داخلِ بازی** — از روی کارهای قانونیِ همین بازیکن ساخته می‌شود؛
«بازی جدید»/«بلیتز» وسط بازی دیده نمی‌شوند (زدنشان بازی را دور می‌انداخت).

**🏳️ تسلیم** — دو مرحله‌ای، بدون افشای نقش.
